# GH-516

**Created:** 2026-09-28

## Problem

GitHub Issue GH-516: feat(profile): PUT /auth/me updates the display name (TASK-501 leg A, auth-service part)

## Context

The Pilot console Profile page (pilot-console-ui, GH-174) is read-only because auth-service has no profile-update route. Users need to change their display name. Email change is a separate, later leg (needs the email transport); do not touch email here.

## Change

Add an authenticated profile update, modelled exactly on the password change (`internal/api/router.go` line 139, `internal/api/auth_handlers.go` ChangePassword, `internal/auth/service.go` ChangePassword):

- Route: PUT /auth/me on the protected group, request body {"name": "<string>"}, validated via the existing ValidateReq helper with a new ProfileUpdateRequest in `internal/domain/validation.go`: name required, trimmed, 1 to 80 characters, no control characters.
- Service: Service.UpdateProfile(ctx, userID, name) in `internal/auth/service.go`: load the user (same lookup GetMe uses at line 564), set Name, persist, write audit event EventProfileUpdated (add the constant in `internal/audit/audit.go` next to EventPasswordChange), return the updated api.UserInfo (`internal/api/services.go`).
- Storage: add UpdateName(ctx, tenantID, userID, name) to the user repository interface and to PostgresUserRepository in `internal/storage/user_repository.go` (same shape as UpdatePasswordHash at line 217, tenant-scoped); update `internal/storage/mocks/user_repository.go`.
- Response: 200 with UserInfo {id, email, name}. 401 without a valid access token (protected group already does this). 422 on validation failure with the existing error shape.
- OpenAPI: add the /auth/me PUT operation to `api/public.openapi.yaml` next to /auth/me/password (line 178); spectral must stay clean.
- No new env, no migration (users.name already exists, `internal/domain/user.go` line 15).

## Acceptance

- Handler test in `internal/api/router_test.go` style: 200 updates the name and GET /auth/me returns it; 422 on empty and on 81-char names; 401 unauthenticated.
- Service test: audit event written once with the user id; repository UpdateName called with the caller's tenant and user id only.
- Integration test in `internal/api/auth_integration_test.go` style if that suite runs in CI.
- spectral clean; go vet and the existing test suite green.
