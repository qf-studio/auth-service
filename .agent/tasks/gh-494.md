## Context

Depends on the `e2e` package harness from issue A. Review-003 confirmed-but-unfixed gaps this issue turns into executable acceptance criteria: audit_logs never written; arbitrary scopes accepted on client create; `X-Tenant-ID` resolution unwired; RBAC middleware applied to no route; HIBP never called. (See DEVELOPMENT-README Current Focus wave-2 list.)

## Task

1. **Golden route list**: a table of every expected `(method, path)` on the public and admin routers (~70 endpoints, derive from `internal/api/router.go` and `internal/api/admin_router.go`); black-box assert each answers non-404 (any of 200/400/401/405 acceptable — the assertion is "the route mounts"). A route disappearing or a nil-guarded group silently unmounting fails this test with a named diff.
2. **Wiring assertions**:
   - After an admin action (create user), `audit_logs` row count grows — query Postgres directly. Currently false → write as `t.Skip` (see 3).
   - After `/auth-migrate up`, `schema_migrations` version equals the embedded head (read dynamically from the migrations FS, no hardcoded number — avoids the GH-485 head-test trap).
3. **Wave-2 acceptance tests, written now, skipped**: each as a real test with `t.Skip("review-003: <topic> — unskip when fixed")`:
   - audit_logs persists admin events
   - client create with scope `not-a-real-scope` is rejected 400
   - request with `X-Tenant-ID` of an unknown tenant is rejected (not silently defaulted)
   - user-role access token calling an admin-scoped route is rejected
   - register with a known-breached password (HIBPMock returns hit) is rejected
   The wave-2 fix PRs unskip their test — the suite becomes the backlog's acceptance harness.
4. **P1 negatives**: reuse of a revoked access token → 401; expired access token (run SUT with a seconds-level TTL env) → 401; login rate-limit → 429 with retry semantics; `/liveness` vs `/readiness` semantics (readiness fails when Redis container is paused, liveness doesn't); `GET /metrics/prometheus` output parses as Prometheus text format.

## Acceptance criteria

- Route-list test fails with a clear message when a route group is removed from the router (verified by temporarily commenting one in a scratch branch — describe in PR, don't commit).
- All skipped tests carry the `review-003:` skip-reason convention and run (as skips) in CI.
- Negative-path tests green; full `go test ./e2e/` stays under the 20m CI budget.
- `go test -short ./...` still clean without Docker.

## Non-goals

Fixing any wave-2 gap itself; fault injection beyond the Redis-pause readiness check; smoke image; canary.
