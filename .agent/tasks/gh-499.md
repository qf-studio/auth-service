## Problem

A4 of the E2E plan (`.agent/tasks/TASK-01-e2e-canary-strategy.md`): admin-surface and gRPC golden paths on top of the A1 harness (#493).

## Context

Depends on the `e2e` package from #493. gRPC exercised through `pkg/authclient` (the published SDK) against the SUT's port 4002 — SDK breaks must fail E2E. Admin API is on port 4001 (no auth by design currently — network isolation; tests hit it directly).

**Execution-environment note**: without Docker locally, verify via `go build ./...` / `go test -short ./...` and rely on the e2e CI job.

## Task

1. **Admin client lifecycle**: create client (`service` type) → returned `qf_cs_` secret → rotate secret → old secret still exchanges during the 24h grace (assert via `/oauth/token` client auth or the documented client-auth path) → new secret works → update scopes → soft-delete → operations on deleted client fail.
2. **API-key lifecycle** (regression guard for GH-485): create → validate → rotate → old key valid in grace, new valid → revoke → both rejected. Validation via the service's API-key consumption path; if no public endpoint consumes API keys yet, drive `ValidateAPIKey` through whatever surface exists and document the gap in a test comment referencing review-003.
3. **gRPC via `pkg/authclient`**: ValidateToken (valid token → claims; garbage → error; revoked token → still valid, documented as the known ValidateToken-skips-revocation gap with a review-003 comment), IntrospectToken (valid + revoked → `active:false`), GetUser.
4. Assert gRPC reachable on the compose-published port 4002 (regression guard for the docker-compose port gap fixed in 2333a60 — here against the image's exposed port).

## Acceptance criteria

- All lifecycles green in CI; grace-window assertions use injected clocks or short config windows, not real 24h waits (document the chosen mechanism).
- gRPC tests go through `pkg/authclient` public API only.
- `go test -short ./...` clean without Docker; lint clean.

## Non-goals

Webhooks admin CRUD (dead until wave-2 wires Dispatch); tenants/SAML/broker groups (nil-guarded, never mount); wiring assertions (#494).
